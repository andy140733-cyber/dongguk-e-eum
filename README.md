# 동국e음 (Dongguk e-eum)

동국대학교 교육학과 재학생, 졸업생, 교수진을 위한 폐쇄형 학과 종합 소통 플랫폼(1차 프로토타입)입니다.

## 주요 기능
- **홈 대시보드**: 역할(재학생 / 졸업생 / 교수 / 관리자) 전환에 따른 맞춤형 바로가기 및 요약
- **학교·학과 공지**: 학교 공지, 교육학과 공지, 학사 일정, 장학 및 지원, 교직 관련 안내 분류·검색·고정 (`[예시 데이터]` 명시)
- **대화창 (메신저)**: 교수-학생 면담 요청, 선후배 1:1 대화, 다중 초대 단체 채팅방 개설 및 메시지 전송
- **진로·복수전공 공유방**: 7대 진로 트랙 및 확장형 복수전공 공유방 아카이브 (질문/답변, 복수전공 후기, 진로 경험 공유)
- **졸업생 동문 연결**: 진로·복수전공별 선배 탐색, 개인정보 공개 범위 설정, 1:1 대화 및 멘토링 신청
- **졸업요건 자가점검**: 허위 기준값을 넣지 않고 `기준 미설정`을 기본으로 하는 안전한 학점·교육봉사·체크리스트 자가점검
- **회원가입·승인 및 관리자 센터**: 가입 신청, 소속 인증 안내, 승인 대기/보완 요청 화면 및 관리자 승인·역할·신고 관리

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.
